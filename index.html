🧠 Mental Model #1

Bagaimana Komputer Berpikir? (Model IPO)

Komputer sebenarnya mesin yang "patuh tapi polos". Ia hanya menjalankan 3 siklus:

1. INPUT (Masukan)

Data dari ketikan keyboard, klik mouse, sensor, atau jaringan kabel LAN.

Contoh: input("Nama?")

2. PROCESS (Proses)

CPU mengolah instruksi koding, menghitung data & memeriksa logika if-else.

Contoh: nama = "Ahmad"

3. OUTPUT (Keluaran)

Hasil ditampilkan ke layar monitor, suara speaker, atau aksi router.

Contoh: print("Halo Ahmad!")

📦 Konsep Koding #2 & Kuis

Variabel & Jebakan Tipe Data

Variabel adalah kotak memori berlabel untuk menyimpan Teks (String), Angka (Integer), atau Boolean (True/False).

Kuis Interaktif 1: Tebak Hasil Kode Ini!
Kasus 1 (Angka Murni):
print(10 + 10)
Kasus 2 (Pakai Tanda Kutip):
print("10" + "10")

Menurut kalian, apa hasil keluaran kedua kode di atas?

JAWABAN BENAR: OPSI B! 🎉

• Angka 10 + 10: Dihitung matematika $\to$ 20.
• Teks "10" + "10": Dianggap kata yang disambung (*Concatenation*) $\to$ "1010"!

🚦 Konsep Koding #5 & Kuis

Logika Keputusan: if - else

Komputer mengecek kondisi: JIKA (if) benar lakukan A, JIKA TIDAK (else) lakukan B.

Geser Nilai Ujian Siswa: 80 
nilai = 80
if nilai >= 75:
    status = "AKSES DITERIMA / LULUS 🟢"
else:
    status = "AKSES DITOLAK / REMEDIAL 🔴"
GERBANG TERBUKA (AKSES DITERIMA)
Kuis Interaktif 3: Logika Syarat
umur = 16
if umur >= 17:
print("Boleh Buat SIM")
else:
print("Belum Cukup Umur")

Apa teks yang akan dicetak komputer?

✔ BENAR! OPSI B: "Belum Cukup Umur"
Karena 16 tidak lebih besar atau sama dengan 17, komputer langsung lompat ke blok else!
